# Novedades de Gastos Claros v1.1

- Gráfico circular de salidas de dinero por categorías: todas las áreas de gasto y «Inversiones» como apartado independiente.
- Nuevo resumen mensual de cuatro importes: gasto de consumo, ingresos, inversión y liquidez libre estimada.
- Las inversiones también aparecen en la comparativa de seis meses y en el gráfico anual (en diferente color).
- Se mantienen la misma base de datos local `gastos-claros-v1`, todos los tipos de movimientos y el formato de copia de seguridad JSON.
- Caché PWA actualizado para que el iPhone reciba los nuevos archivos.

**Antes de actualizar**: descarga la copia JSON desde la app.
**Subida GitHub**: reemplaza los archivos `app.js`, `style.css`, `sw.js` y `LEEME.md`; añade `CAMBIOS_v1.1.md`. No cambies ni borres la dirección de GitHub Pages.
