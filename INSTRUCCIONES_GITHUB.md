# Publicar Gastos Claros en GitHub Pages

Repositorio de destino: https://github.com/jruial/Gastos-claros

1. Descomprime este ZIP. **No subas el ZIP sin descomprimir.**
2. En GitHub, abre tu repositorio, ve a **Add file > Upload files** y arrastra los archivos `index.html`, `app.js`, `style.css`, `manifest.webmanifest`, `sw.js`, `LEEME.md` y la carpeta `icons` con sus dos imágenes. Al subir, comprueba que `index.html` quede en la raíz y que la ruta `icons/icon-192.png` exista. Pulsa **Commit changes**.
3. Abre **Settings > Pages**, bajo **Build and deployment** elige **Deploy from a branch**, selecciona `main` y `/ (root)` y guarda. GitHub publica el sitio en https://jruial.github.io/Gastos-claros/ una vez que el despliegue termine.
4. Abre esa dirección en Safari del iPhone, pulsa Compartir > Añadir a pantalla de inicio.

IMPORTANTE
- No subas extractos, CSV o archivos JSON con tus datos financieros a GitHub.
- Los movimientos se almacenan localmente en cada navegador: haz copias JSON desde Ajustes antes de cambiar de dispositivo o borrar datos.
- La aplicación es una versión inicial, sin sincronización bancaria automática.
